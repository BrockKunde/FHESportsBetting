# React Template for FHEVM

React template for building confidential dApps with FHEVM SDK.

## Available Examples

For complete React implementations, see our examples:

- **[Sports Betting Platform](../../examples/sports-betting/)** - Full-featured React app with FHEVM
- **[Next.js Showcase](../../examples/nextjs-showcase/)** - Next.js + React with complete SDK integration

## Basic Setup

```bash
# Install dependencies
npm install @fhevm/sdk ethers react react-dom

# Use SDK hooks
import { useFhevmClient, useEncryptInput } from '@fhevm/sdk/react';
```
