# Next.js Template for FHEVM

This directory serves as a reference to the complete Next.js example implementation.

## Full Implementation

For the complete Next.js template with SDK integration, see:

**[examples/nextjs-showcase](../../examples/nextjs-showcase/)**

The showcase includes:
- Complete App Router structure
- SDK integration with React hooks
- API routes for FHE operations
- UI components and examples
- Configuration files

## Quick Start

```bash
cd ../../examples/nextjs-showcase
npm install
npm run dev
```
